OneDrive Excel sync
One-time setup (Power Automate):
  1. Open make.powerautomate.com → Create → Instant cloud flow.
  2. Trigger: When an HTTP request is received. Save once to get the URL.
  3. Paste this JSON schema in the trigger:
    {"type":"object","properties":{"timestamp":{"type":"string"},"device_name":{"type":"string"},"manufacturer":{"type":"string"},"model":{"type":"string"},"serial":{"type":"string"}}}
  4. Add action: Excel Online (Business) → Add a row into a table. Pick your .xlsx in OneDrive and the table (must be a real Excel table — select rows → Insert → Table).
  5. Map columns to the trigger fields. Save the flow. Copy the HTTP URL into the box above.
Your Excel table should have columns: timestamp, device_name, manufacturer, model, serial.
